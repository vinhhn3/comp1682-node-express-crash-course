! The two rules behind the picture

1 · Only the repository touches the model

A controller that writes Product.find() has become a repository with extra steps. The day you add a cache, a second database or a different shape, you edit HTTP code. 

// controller — right
const products = await productRepository.findAll(q);

// controller — wrong
const products = await Product.find({ title: q });

2 · Only the controller touches req and res

A repository that reads req.body cannot be called from a seed script, a job, or a test without faking an HTTP request. Plain data in, plain data out. 

// repository — right
async create(data) { return Product.create(data); }

// repository — wrong
async create(req, res) { … }
